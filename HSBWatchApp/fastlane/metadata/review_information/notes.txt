[How to Test Without External TV / Mac Hardware]:
This application is designed as a wireless companion controller for smart TV screens and computers. To ensure a smooth, complete, and convenient review experience—even if your testing environment does not have a physical TV or computer running on the local Wi-Fi:

1. Launch the app on iPhone / iPad.
2. On the main home screen, tap the Remote icon located on the top-right navigation bar (the modern remote controller icon next to Settings and QR scanner).
3. This directly opens the full-featured modern remote controller interface, allowing you to test and evaluate all interactive capabilities:
   - System Remote Tab: Tactile D-pad directional navigation wheel, center OK confirmation, media playback controls (seek 10s backward/forward, play/pause), system hardware keys (Home, Menu, Mute, Standby), and volume stepper buttons. Every interaction delivers realistic iOS Taptic Engine feedback.
   - Touchpad Tab: Precision wireless trackpad simulating mouse cursor gliding, two-finger smooth scrolling, left/right clicks, and an intuitive "Fullscreen" button to toggle immersive fullscreen trackpad mode.
   - IPTV Tab: Classic dual-tower CH+/- and VOL+/- controls, quick channel shortcuts, and numeric keypad dialing.
   - PDF Presentation Tab: Presentation slide turners, first/last slide jumping, and an interactive drawing whiteboard supporting multi-color drawing and stroke undo.
   - Text Input Drawer: Tap the keyboard button in the top bar to pull up the text input drawer, supporting synchronized text sending and the native Backspace key.
4. From the main screen, tap the Gear icon (top-right) to access Settings, including On-Device AI Model Center, Translation settings, and the in-app Privacy Policy.
